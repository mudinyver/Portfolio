# **Intitulé du projet :** Base de donnée sur le foot

<img src="../.readme_images/server.png" alt="" width="100em">

**Identifiant et libellé universitaire :** SAÉ 1.04 - Création d'une base de données

**Année :** 2024/2025

**Description succincte du projet :**

Création d’une base de donnée, en plusieurs étapes :
 - analyse des besoins clients,
 - rédaction des dépendances fonctionnelles,
 - conception du diagramme de classes et
 - création de la base de donnée

**Cadre :**
Réalisé dans le cadre d’un projet universitaire en binôme.

**Technologies :**
Utilisation de Visual Studio Code. Programmé avec le langage Tutorial D.


**Résultats :**
La base de données répond aux exigences.

**Aptitudes personnelles développées :**
Organisation du travail en équipe, créativité, prise d’initiative.

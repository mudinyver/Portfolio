**Identifiant et libellé universitaire :** Non applicable (projet personnel)

**Année :** 2022/2023

**Description succincte du projet :**

Création d’un modpack minecraft :
 - supprimer certains crafts,
 - cacher certains items,
 - supprimer certains minerais
 - créer des crafts
 - créer des items

**Cadre :**
Réaliser en monôme dans le cadre d’un projet personnel en avril 2024.

**Technologies :**
Utilisation (et découverte) de Visual Studio Code et de GitHub. Programmé avec json et zenscript
Utilisation de l’outil KubeJS

**Résultats :**
Le GitHub n’est pas à jour et j’ai perdu le code source mais le modpack est fonctionnel. J’ai changé d’outil pendant le projet pour pouvoir mettre le modpack sur un serveur en ligne car le serveur ne supportait pas KubeJS.

**Aptitudes personnelles développées :**
Organisation du travail, créativité, résolution de problèmes.

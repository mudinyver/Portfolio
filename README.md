# Portfolio
Portfolio de Mael UDIN--YVER, IUT de Lannion

Projet : SAÉ 1.01
Année : 2024/2025

Intitulé du projet :  Snake en C

Description succincte du projet :
Création d’un jeu snake, en 5 étapes :
- création et mise ne place d’un déplacement rudimentaire (AC11.01)
- déplacement avancé du serpent (AC11.01)
- création de collisions (AC11.01)
- collisions et déplacement avancés (AC11.01)
- création de la documentation (AC11.01)

Note : Un cahier de tests est crée à chaque étape (AC11.03)



Cadre :
Réaliser dans le cadre d’un projet universitaire en monôme.


Technologies :
Utilisation de Visual Studio Code et du Terminal. Programmé avec le langage C.


Résultats :
Le jeu a été fini avec succès. Il est opérationnel et présentable.


Aptitudes personnelles développées :
Créativité, résolution de problèmes divers.
